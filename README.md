# Arsenal Hub Script

A feature-rich Roblox Arsenal script with ESP (Enemy/Team), Camera Aimbot with FOV circle, Random Body Part Target Lock per session, Smoothness controls, Auto-Save/Load Config, Mobile Touch Support, and Floating UI Toggle.

## Quick Loader (Roblox Executor)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/LOCAL2/arsenal-script/main/Source/ArsenalHub.lua"))()
```

## Features
- **Camera Aimbot**: Locks camera onto selected body parts with customizable FOV & Smoothness.
- **Mobile Mode**: Support for Always-Lock and a Floating Touch Toggle button (`🎯`).
- **ESP**: Custom highlight colors, Team Check, Enemy Only mode, HP status, NameTags, and Distance meters.
- **Auto Config**: Saves user options automatically to `ArsenalHub_Config.json` and restores them on load.
